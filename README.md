# EA-Legacy-Compression-Formats
A collection of original and faithfully reconstructed compression algorithms used in classic Electronic Arts (EA) games. This repository includes officialy released source code and AI-assisted reverse-engineering implementations extracted from original game executables. The reconstructed routines reproduce the original compression output byte-to-byte, generating files identical to those produced by the original games. Examples of classic EA games that use these formats in their internal game assets include all Need for Speed titles releases for consoles and PC between 2000 and 2010, as well as games from the Harry Potter and Madden NFL series. The reverse-engineered, AI-assisted implementations that produce byte-identical output to the original routines are COMP, JDLZ and EA Madden. The remaining implementations are original source code officially released by EA.
